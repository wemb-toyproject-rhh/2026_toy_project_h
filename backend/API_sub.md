## 패스워드 찾기(재설정) API

로그인 화면 하단 "패스워드 찾기" 페이지에서 쓸 API입니다. 로그인 자체가 안 되는
상황(비밀번호를 잊음, 또는 탈퇴)에서 쓰는 거라 **인증 불필요**, 현재 비밀번호 확인도
안 합니다.

`PUT /api/rhh/users/password-reset`

**화면 구성 제안**: 아이디 입력창 1개 + 새 비밀번호 입력창 1개, 제출 버튼 하나면 됩니다.

**요청**
```json
{ "userId": "string", "newPassword": "string (4자 이상)" }
```

**성공 (200)**
```json
{ "ok": true }
```

**에러**
- `400` 아이디 미입력 / 비밀번호 4자 미만
- `404` 존재하지 않는 아이디 (`{ "error": "존재하지 않는 아이디입니다" }`)

**동작 관련 참고**
- 성공하면 비밀번호만 바뀌는 게 아니라 **탈퇴(`use=false`)한 계정도 자동으로
  재활성화**됩니다(`use=true`로 바뀜). 즉 탈퇴했던 아이디도 이 화면에서 비밀번호를
  다시 설정하면 바로 로그인할 수 있게 됩니다.
- 아이디만 맞으면 본인 확인 절차 없이 바로 바뀝니다(이메일 인증 같은 본인 확인
  수단이 없어서 의도적으로 이렇게 열어둔 상태) — 화면에서 "정말 변경하시겠어요?"
  같은 확인 문구 정도는 넣어주면 좋을 것 같습니다.

**화면 흐름 예시**
1. 아이디, 새 비밀번호 입력 → 제출
2. `200` 오면 → "비밀번호가 변경되었습니다" 안내 후 로그인 화면으로 이동
3. `404` 오면 → "존재하지 않는 아이디입니다" 에러 표시 (그대로 사용 가능한 문구)
